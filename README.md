# 소하천 조사

현장에서 사진을 찍으면 GPS 좌표·유형·방향·메모를 함께 기록하고,
하천별로 ZIP(사진 + CSV + GeoJSON)으로 내보내는 웹앱입니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 |
| `sw.js` | 오프라인 캐시 (앱 + 위성 타일) |
| `manifest.webmanifest` | 홈화면 설치 정보 |
| `icon.svg`, `icon-maskable.svg` | 아이콘 |

## 올리는 법 (GitHub Pages 기준)

```
1. GitHub에서 새 저장소 생성 (public)
2. 이 폴더의 파일 5개를 올린다
3. Settings → Pages → Source: main / (root) → Save
4. 몇 분 뒤 https://<계정>.github.io/<저장소>/ 로 접속
```

**https가 필수입니다.** 파일을 그냥 열거나(`file://`) http로 띄우면
브라우저가 GPS를 막습니다.

접속 후 크롬 메뉴 → **홈 화면에 추가** 하면 앱처럼 전체화면으로 실행됩니다.

## 브이월드 위성영상

설정에서 API 키를 넣고 "브이월드 항공사진"을 고릅니다.
키는 브이월드 사이트에서 **서비스유형: 웹사이트**, **서비스URL: 이 앱 주소**로
발급받아야 합니다. QGIS용 키(기타 유형)는 브라우저에서 거부됩니다.
QGIS는 Referer를 안 보내서 등록 없이 되지만 브라우저는 검사합니다.

등록 전이거나 타일이 계속 실패하면 Esri 위성영상으로 자동 전환됩니다.
저장된 설정은 그대로라 앱을 다시 열면 브이월드를 다시 시도합니다.

### 부서원에게 키 넘기기

API 키는 저장소에 넣지 않습니다. public 저장소에 커밋하면 git 이력에
영구히 남고 수집 봇에 긁힙니다.

대신 설정 화면의 **설정 링크 복사**를 눌러 나온 링크를 메신저로 보냅니다.

```
https://yunhongyeol.github.io/sohacheon-survey/#k=<키>
```

받은 사람이 이 링크를 한 번 열면 키가 그 폰에 저장되고 주소에서는
지워집니다. 그 뒤로는 홈 화면 아이콘만 쓰면 됩니다.
조사자 이름은 각자 설정에서 따로 넣습니다.

## 통신이 끊기는 곳

- **GPS·촬영·메모는 통신과 무관하게 동작합니다.** 위성지도 타일만 못 받습니다.
- 통신 되는 곳에서 지도 탭 → **이 영역 오프라인 저장** 을 눌러 답사 구간을
  미리 받아두면 현장에서도 위성영상이 보입니다.

## 내보내기 결과

```
당동천_20261008_161230.zip
└ 당동천/
   ├ 당동천_시점_하류방향_20261008_143022.jpg
   ├ 당동천_교량_당동교_하류방향_20261008_145510.jpg
   ├ 당동천_낙차공_상류방향_20261008_151004.jpg
   ├ 당동천_기록.csv        ← 엑셀 바로 열림 (파일명·좌표·유형·메모)
   └ 당동천.geojson         ← QGIS에 바로 끌어다 놓으면 점으로 표시
```

부서원 여러 명이 나눠 다녀도 파일명에 하천명과 촬영시각이 들어 있어
폴더에 모으기만 하면 합쳐집니다. 조사자 이름은 CSV에 들어갑니다.

## 주의

- 사진은 브라우저 저장소(IndexedDB)에 있습니다. **하천 하나 끝낼 때마다
  내보내기를 눌러 실제 파일로 빼두세요.** 크롬 저장소를 비우면 사라집니다.
- 방위각은 휴대폰 나침반 값이라 참고용입니다. 금속 구조물 옆에서는 틀어집니다.
